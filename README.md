# PV Battery Charger IC Thesis

## Project Structure

### `mppt_simulink_model/`
Contains the MPPT (Maximum Power Point Tracking) simulation models and Fuzzy Logic controller implementation:
- **block_design/**: Simulink models for the MPPT system
- **fis_rules/**: Sugeno fuzzy inference system creator and rules
- **model_paramters/**: Buck converter parameters and configurations

### `externalworks_papers/`
Reference materials for external researchers working on similar topics and this thesis's research paper:
- **ieeepapers.txt**: List of relevant IEEE papers
- **smacd_paper/**: SMACD 2026 conference paper trial in LaTeX format

### `thesis_documentation/`
Complete LaTeX thesis documentation with supporting materials:
- **thesis.tex**: Main thesis document
- **references.bib**: Bibliography references
- **codes_models/**: MATLAB code, Verilog-A models, and SystemVerilog implementations
- **figures/**: Visual materials, CAD designs, and MATLAB simulation plots

### `notes/`
Working notes and preliminary calculations
- **presentations/**: progress related old presentations
